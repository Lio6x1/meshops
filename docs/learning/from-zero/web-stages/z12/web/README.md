# MeshOps 正式控制台

Vue 3 + TypeScript + Vite + Element Plus。页面调用同源 `/api`，业务数据来自真实 Go 服务；这里不含模拟 API 或浏览器持久化凭证。业务入口包括实体总览、实体资源、任务中心、任务检索、可靠分发、运行状态和模拟演示；管理员还可管理账号，两种角色均可修改自己的密码。

## 学习调试

1. 按参考工程的 `docs/run-fullstack.md`完成本机迁移和构建，启动中间件、业务服务及 HTTP 网关（默认 `127.0.0.1:18090`）。首次使用时在工程根目录的 PowerShell 7 执行 `./scripts/account-admin.ps1 -Mode Local -Action Setup -Username admin`，按提示设置管理员密码。Docker 模式省略 `-Mode Local`，账号保存在所选环境的数据库中；重复 Setup 不会重置已有管理员。初始化和恢复步骤见参考工程的 `docs/operations/accounts.md`。
2. 在本目录运行 `npm ci`，然后 `npm run dev`。如果本机 `npm.ps1` 损坏，可在工程根目录使用 `scripts/frontend.ps1` 入口。
3. 打开 `http://127.0.0.1:5173`，使用个人用户名和密码登录，角色由账号决定。管理员在“账号管理”创建操作员；操作员首次登录或密码被重置后，必须先修改密码，再用新密码重新登录。完成改密之前，页面和后端均阻止进入业务功能。Vite 将 `/api` 代理到网关，保留浏览器 Origin；仅启动前端不会生成业务数据。
4. 退出用页面“退出”按钮，停止开发服务器用 `Ctrl+C`。密码只在输入与提交期间保留于内存，不写入浏览器持久存储，会话由 HttpOnly Cookie 承载。两种角色均可通过“修改密码”更新自己的密码，成功后需要重新登录。

`npm run build` 执行 TypeScript 类型检查并生成 `dist/`；`npm test` 运行 Node 原生领域与 HTTP 适配测试。精确依赖版本与 `package-lock.json` 一并纳入版本控制。Node 要求至少 22.12，建议与部署 Node 24 一致。

## 演示流程

- 在实体总览等待“同步完成”，查看六种类型、快照新鲜度；实体资源的详情包含类型专属字段和历史采样查询。
- 在任务中心选择新鲜且空闲的执行实体，创建 1–60 秒巡检；详情自动查询任务状态与持久化历史。取消仅提交意图，不把意图显示成已停止。
- 任务检索支持关键词、状态、实体和时间范围；签名游标不能任意跳页。快照过期时保留条件并重新开始。打开结果后从任务服务读取权威状态。
- 在可靠分发页面输入任务 ID，查看最新或指定单条分发。只有管理员且返回 `delivery_status=dlq` 才可填写原因重试；最终决定权在后端。
- 管理员运行状态显示真实的 consumer_lag、active_tasks、dlq_count 和采样时间；不推断整套系统健康，也不制造趋势数据。
- 在模拟演示调整六类实体的数量（每类 0—5 个），切换正常上报、暂停采集和断网缓存，在地图观察新鲜度与恢复补传。数量与期望模式需等待后台实际状态确认；具体步骤见参考工程的 `docs/simulation-map.md`。
- 管理员在账号管理创建操作员、启用或停用账号、重置密码。停用或重置会撤销该账号已有会话；页面不提供创建管理员或停用管理员的操作。

## 一致性约束

64 位实体版本和计数保持字符串；版本比较使用 BigInt。optional 缺值显示未知，已存在组件的普通 proto3 标量按默认零值语义处理。SSE 断线保留最近状态并撤销同步完成标志，新连接等待新的 SNAPSHOT_END；事件删除与视图代次变化分别处理。创建请求在首次发送后冻结参数及幂等键，结果不确定时重试完全相同的请求。

自动测试覆盖以上领域规则和 HTTP 错误、CSRF、游标编码。真实浏览器的布局、键盘交互与完整后端联调属于工程统一验收，由根目录验收记录给出结果。
