# 搜索前置实现检查与 Z09 固定

本记录覆盖搜索前的重点基础检查，不能替代全工程最终复核，也不能证明搜索闭环已完成。

## 已检查与修正

- 凭证为随机 32 字节机器令牌，SHA-256 用于摘要查找和恒定时间比较，不是用户密码方案。项目没有注册/密码登录功能。
- 原明文 gRPC 可配置外网监听或外部连接。本次在 LoadConfig/Dial 中拒绝非回环 IP，保留本机模拟模式；没有实现生产 TLS、密钥托管或凭证轮换。
- Task SQL 参数化；租户来自可信身份；创建的任务、审计与 Outbox 同事务；状态变化在行锁内推进版本。HMAC 游标绑定租户和筛选条件。
- 订阅重连计数从“准备等待重试”调整为“实际发起下一次订阅”，避免观察窗口在退避期间结束也增加计数。先复现再修正，并增加无网络的定向测试。
- 可搜索文字是任务实例的 note 和取消/失败原因。TaskDefinition.description 是类型说明，inspect 结果结构保持原契约。

解释见 [实现检查讲解](../lessons/implementation-review.md)。
