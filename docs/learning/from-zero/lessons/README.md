# 从零课程阅读顺序

基础实现的工程边界与两处修正见 [实现检查讲解](implementation-review.md)。

全程只在自己的 `D:\job\golang\projects\meshops-course-lab` 中逐步增加代码，根目录保留最终完整实现，旧骨架已删除。module保持 `example.com/meshops-course`，不要求购买域名。Z表示阶段，带后缀编号表示阶段内学习单元；这些不是旧L课程的直接编号替换。

教材留在参考仓库的 `docs/learning/from-zero/`，学习目录只复制阶段清单中的源码和必要文件。复制过去的 README 中指向 `docs/` 的链接属于参考仓库导航，请回到原仓库阅读；无需再把整套教材复制进自己的 Go 工程。

排错贯穿学习过程：[日志与排错实操](debugging.md)。Z02先读输出与错误层次，Z04结合身份和参数校验，Z07装配后运行四种真实错误及恢复实验；提供完整诊断脚本，不要求自己猜日志位置。

每阶段先阅读问题与协议，再按讲义顺序看实现，最后完成该阶段文件并运行。解释片段只帮助理解，复制代码使用“完整文件答案”；生成文件可按脚本生成或复制明确链接中的整份文件。不要把代码围栏或file注释标记粘进Go文件。

两条路线选一条持续使用：手工路线从空目录按文件答案创建、替换及移除；受管理路线从空目录依次运行 [apply-checkpoint.ps1](../apply-checkpoint.ps1)。二者输出相同业务代码，手工路线不需要也不应伪造受管理路线的阶段记录。

Z04—Z09共20个步骤均提供 [精确操作、完整文件清单及指定测试](steps/README.md)，验证范围从协议编译、规则、本地持久化逐步增加到真实Redis/Kafka/MySQL。没有测试的协议步骤与需要真实依赖的步骤分别标明。完整故障、性能、学生操作路线与教学理解仍单独核对，不以文件齐全代替全部验收。

Z10 另加三个可构建步骤，共 23 步。先停止 Z09 进程，在同一个学习目录按新增步骤升级；原九个阶段的代码已冻结。根工程继续维护最终实现，Z10 文件清单从根工程的显式源码范围生成，排除本机凭证、运行数据和缓存。

完整阶段启动命令及环境切换见 [运行手册](../CHECKPOINTS.md)。脚本化文件核对只证明复制内容没有缺口，不证明你已经理解；完成后应能独立解释为什么确认后仍可能重发、为什么取消不等于停止、为什么lag为零不证明恢复完整。
