## 执行

本步需要真实依赖：Redis、Kafka。先按[依赖接线说明](remaining.md)设置测试环境；SKIP或未发现指定测试均不算通过。

```powershell
Set-Location 'D:\job\golang\projects\meshops-course-lab'
$env:Path = 'D:\go1.25.10\bin;' + $env:Path
$env:GOWORK = 'off'
go build ./...
if ($LASTEXITCODE -ne 0) { throw 'build failed' }
go test ./internal/state -run '^(TestRedisAtomicOrderingAndTombstone|TestKafkaACKThenRedisProjection)$' -count=1 -v
if ($LASTEXITCODE -ne 0) { throw 'test failed' }
```

构建成功通常没有输出。测试必须出现下列顶层测试的PASS；[no tests to run]不是通过本步骤。
- `TestRedisAtomicOrderingAndTombstone`
- `TestKafkaACKThenRedisProjection`
