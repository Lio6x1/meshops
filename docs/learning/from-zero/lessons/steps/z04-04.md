## 执行

```powershell
Set-Location 'D:\job\golang\projects\meshops-course-lab'
$env:Path = 'D:\go1.25.10\bin;' + $env:Path
$env:GOWORK = 'off'
go build ./...
if ($LASTEXITCODE -ne 0) { throw 'build failed' }
go test ./internal/state -run '^(TestAuthenticatedWriteQueryAndVolatileRestart|TestMemoryVersionAndTenantRules)$' -count=1 -v

```

- `TestMemoryVersionAndTenantRules`
