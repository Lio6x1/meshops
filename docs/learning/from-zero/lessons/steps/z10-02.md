## 执行

```powershell
Set-Location 'D:\job\golang\projects\meshops-course-lab'
$env:Path = 'D:\go1.25.10\bin;' + $env:Path
$env:GOWORK = 'off'
go build ./...
if ($LASTEXITCODE -ne 0) { throw 'build failed' }
go test ./internal/search -run '^(TestCanalFullRowsAndSafeProjection|TestCanalMySQLEnumOrdinal|TestHandlerOnlyAcknowledgesWholeMessage|TestIndexVersionConflict|TestSearchTenantPagingAndCursorBinding|TestSearchServiceUsesTrustedTenantAndReadiness|TestResetTaskIndexRefusesOtherResources)$' -count=1 -v
if ($LASTEXITCODE -ne 0) { throw 'test failed' }
```

构建成功通常没有输出。测试必须出现下列顶层测试的PASS；[no tests to run]不是通过本步骤。
- `TestCanalFullRowsAndSafeProjection`
- `TestCanalMySQLEnumOrdinal`
- `TestHandlerOnlyAcknowledgesWholeMessage`
- `TestIndexVersionConflict`
- `TestSearchTenantPagingAndCursorBinding`
- `TestSearchServiceUsesTrustedTenantAndReadiness`
- `TestResetTaskIndexRefusesOtherResources`
