# 明显运动、短轨迹与一万混合实体压测

## 功能变化

人员沿综合楼外围、机器人沿运维站外围巡检，车辆走主路和东南外围道路，无人机作椭圆巡航。路线以事件 occurred_at 推进，数量从一变五不会再导致速度变慢。周期约 35—65 秒，是加速演示；固定传感器和设施不移动。位置、速度组件仍由模拟器通过原业务链路上报。

地图增加“最近轨迹”开关，仅绘制本页收到的最近 30 秒、最多 20 个位置点；不预测位置，不存入浏览器持久存储。重新同步、来源代次变化或移除实体会重建轨迹，长断档不画跨越直线。

[真实 HTTP 位移验收](motion-http.json)覆盖全部 30 个实体：20 个移动实体在约五秒观测间隔内位移均超过 15 米，10 个固定实体位置不变，所有版本继续更新。结束恢复原六个来源设置。浏览器实际显示 30 个新鲜点位、20 条移动轨迹，开关能隐藏为 0 条并恢复为 20 条，固定实体没有轨迹。

## 混合负载与同环境对照

| 类型 | 来源数 | 实体数 |
| --- | ---: | ---: |
| 人员 | 2 | 2000 |
| 无人机 | 2 | 2000 |
| 地面车辆 | 2 | 2000 |
| 巡检机器人 | 2 | 2000 |
| 固定传感器 | 1 | 1000 |
| 设施 | 1 | 1000 |
| 合计 | 10 | 10000 |

每来源使用对应适配器和类型字段。压测从注册表取得原始 ID 和平台 ID；报告记录各类计划数量、实际预热 ACK、实际预热快照及计时阶段接收数量。两种 profile 都逐一核对了 10000 个快照，版本、来源代次与类型正确。

| 模式 | 总提供速率（条/秒） | 实际接收（条/秒） | ACK P99（ms） | 抽样查询可见 P99（ms） |
| --- | ---: | ---: | ---: | ---: |
| mixed | 100 | 99.99 | 1.391 | 2.960 |
| mixed | 500 | 499.90 | 1.449 | 3.053 |
| person | 100 | 99.99 | 1.613 | 3.043 |
| person | 500 | 499.93 | 1.612 | 3.529 |

四个阶段各运行 30 秒，接收错误、生成器排队丢弃、抽样观测遗漏、最终投影 Lag 和历史 Lag 均为 0。原始数据：[mixed](mixed-benchmark.json)、[person](person-benchmark.json)、[环境](environment.json)。这是一轮有界负载验证，不是系统容量上限，也不足以据此断言哪一种类型更快。

**500 条/秒是全部来源的合计速率，不是每个实体 500 条/秒，也不是一万个实体各自每秒更新。** 独立压测只测 Ingest → Kafka → Entity → Redis/MySQL。没有包含网关 bbolt 落盘、任务执行、订阅扇出或一万个地图点位渲染；网页每类 0—5 的演示限制保持不变。

## 环境与采样变化

在 Linux Docker 验证容器内运行同一镜像，验证进程和两个独立服务共享 4 CPU 配额、4 GiB 内存限制，GOMAXPROCS=4。数据库/Kafka/Redis 为已有本机演示依赖，不在这个容器限额内；演示约 12 条/秒的后台上报继续运行。两组压测按 mixed、person 顺序执行，期间没有并行构建或集成测试。Docker 引擎可见 24 CPU、约 15.4 GiB 内存。进程指标中的内存是 Go live heap，不是整个容器或主机内存。

旧采样方式每 50 条取一次，十来源轮换时只会抽中来源 0。当前每 50 条轮换一个抽样位置，覆盖十个来源；100 条/秒阶段 60 个样本，500 条/秒阶段 300 个样本。可见延迟包含查询轮询开销，不代表所有事件的逐条延迟。

2026-09-10 历史结果是 Windows 全人员模式，采样与运行环境不同，因此不直接用旧的延迟和本表比较，也没有覆盖或改写旧报告。

## 复现入口

在本机学习环境按 `scripts/env.ps1` 配置依赖并启动，再运行：

```powershell
./scripts/benchmark.ps1 -Profile mixed -Seconds 30
./scripts/benchmark.ps1 -Profile person -Seconds 30
```

Docker 中的同一工具命令为 `/app/verify --mode benchmark --profile mixed --seconds 30`；运行目录需要 bin/ingest、bin/entity、testdata/sources 和 migrations，并提供 MySQL、Redis、Kafka 环境变量。此次容器以 `/work` 为运行目录，bin 链接到镜像内程序，原始输出持久化挂载到本机 `.local/archives/2026-09-12-motion-mixed/runtime/`。容器退出后独立随机数据库和主题保留，未清理或覆盖演示数据。不要公开访问码、数据库口令或凭证文件。

运动检查用 `python scripts/test-motion.py results/my-motion.json`，同其他演示验收脚本一样，从当前终端读取 `MESHOPS_WEB_OPERATOR_CODE`。浏览器轨迹开关与视觉效果需要单独检查。
