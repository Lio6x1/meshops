# MeshOps 当前界面与交互边界

修订：2026-09-13。本文对应已实现的 Vue 控制台；启动见 [完整手册](../run-fullstack.md)。实际源码为 `web/`，浏览器接入为 `internal/web/`；不再使用固定时钟和内存假数据的离线原型。

## 页面与作用

| 页面 | 作用与边界 |
| --- | --- |
| 实体总览 | 六类实体清单与坐标示意图；区分新鲜、过期和未知信息 |
| 实体资源 | 类型筛选、实体详情和后端抽样历史；不保证完整轨迹 |
| 任务中心 | 创建 inspect、查询事实与审计、提交取消意图；仅四类移动实体具备执行能力 |
| 任务检索 | 查询 ES 任务索引、游标翻页并打开权威详情；索引有同步延迟 |
| 可靠分发 | 查询任务的投递状态；管理员可带原因进行受约束的死信重试 |
| 运行状态 | 管理员查询分发状态；依赖就绪不代表没有积压 |
| 模拟演示 | 六类各 0—5 个，暂停、断网缓存、恢复；区分目标设置与实际状态 |

## 数据与权限

Vue 通过同源 HTTP/JSON 与 SSE 访问网页网关，网关调用 Entity、Task、Dispatcher、Search 的 gRPC 接口。授权实体清单来自网关，浏览器不能自行扩大查询范围。网关持有机器身份，浏览器使用会话 Cookie、角色与写操作 CSRF 校验，不下发来源和执行方令牌。

操作员查看并操作授权资源；分发运行状态和人工重试需要管理员。隐藏按钮仅改善交互，授权必须由服务端执行。实际映射见 [HTTP 配置](../../proto/http.yaml)、[网关](../../internal/web/server.go) 和 [会话](../../internal/web/session.go)。当前不包含用户注册、密码找回或生产单点登录。

## 状态与交互原则

- 未知组件不显示成零；固定传感器与设施不能因为出现在地图上就获得 inspect 能力。
- SSE 断连、同步、失败分别展示；旧快照不冒充新鲜数据，按后端状态判断是否允许任务操作。
- 取消表达意图，终态以任务事实为准；传输重试仍对应原 execution_key，不表示创建了新业务任务。
- 搜索分页过期要重新查询；执行动作前读取任务当前事实，不依靠旧索引内容决定状态迁移。
- 窄屏表格允许局部滚动，状态同时提供文字，表单需要错误反馈；视觉、键盘和响应式效果按实际浏览器验收，不能由构建成功代替。

## 地图与模拟控制

地图根据后端坐标呈现示意园区。人员、无人机、车辆、机器人沿加速模拟路线运动，固定传感器和设施保持位置；不做真实导航或路径优化。最近轨迹只保留本页接收的最近 30 秒、最多 20 个点，重同步和来源代次变化后重新积累，不在前端预测位置。

数量上限是演示界面范围，独立压测采用自己的输入规模。当前有六类混合 10000 实体、100/500 events/s 的限定链路实测，不代表地图可显示 10000 点或已验证百万容量。详细语义、命令和证据见 [模拟场景说明](../simulation-map.md)。
