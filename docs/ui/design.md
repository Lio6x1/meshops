# MeshOps 当前界面与交互边界

修订：2026-09-13。本文对应已实现的 Vue 控制台；启动见 [完整手册](../run-fullstack.md)。实际源码为 `web/`，浏览器接入为 `internal/web/`；不再使用固定时钟和内存假数据的离线原型。

## 页面与作用

| 页面 | 作用与边界 |
| --- | --- |
| 实体总览 | 六类实体清单与坐标示意图；区分新鲜、过期和未知信息 |
| 实体资源 | 类型筛选、实体详情和后端抽样历史；不保证完整轨迹 |
| 任务中心 | 创建 inspect、查询事实与审计、提交取消意图；仅四类移动实体具备执行能力 |
| 任务检索 | 查询 ES 任务索引、游标翻页并打开权威详情；索引有同步延迟 |
| 可靠分发 | 查询任务的投递状态；管理员可带原因进行受约束的死信重试 |
| 运行状态 | 管理员查询分发状态；依赖就绪不代表没有积压 |
| 模拟演示 | 六类各 0—5 个，暂停、断网缓存、恢复；区分目标设置与实际状态 |
| 账号管理 | 管理员分页查看账号、创建操作员、启停和重置操作员密码；初始管理员不提供这些管理按钮 |
| 修改密码 | 管理员和操作员修改本人密码；需要当前密码，成功后重新登录 |

## 数据与权限

Vue 通过同源 HTTP/JSON 与 SSE 访问网页网关，网关调用 Entity、Task、Dispatcher、Search 的 gRPC 接口。授权实体清单来自网关，浏览器不能自行扩大查询范围。浏览器提交用户名/密码并获得不透明的 HttpOnly/SameSite Cookie，写操作检查 CSRF 与 Origin。网关另持有该个人账号的随机内部 RPC 令牌，后端查库解析可信账号 ID、tenant、角色和认证版本；浏览器不能通过角色选择或 actorId 提权。来源、执行方和内部服务继续使用机器凭证，这些凭证不下发到页面。

操作员查看并操作授权资源；账号管理、分发运行状态和人工重试需要管理员。隐藏按钮仅改善交互，授权必须由服务端执行。业务映射见 [HTTP 配置](../../proto/http.yaml)，账号路由见 [账号处理器](../../internal/web/accounts.go)，会话边界见 [网关](../../internal/web/server.go) 和 [会话](../../internal/web/session.go)。当前提供本机管理员初始化/恢复、操作员管理与个人改密，不包含公开注册、邮箱/短信找回或单点登录。

## 账号流程与页面状态

1. 完成数据库迁移和后端构建后，按 [个人账号手册](../operations/accounts.md) 运行 Setup；密码安全输入，不放进启动命令参数。登录页仅显示用户名、密码与错误反馈，没有角色和访问码选择。
2. 管理员打开 `/accounts` 创建操作员，填写用户名、显示名称、初始密码与确认密码。角色固定为 operator；列表每页 20 条，以稳定 ID 游标提供下一页和回到第一页，没有伪造总数。加载中限制重复操作，失败显示重试入口，旧请求不能覆盖新列表或游标。
3. 操作员初始登录后，`mustChangePassword=true` 时外壳只挂载改密页，保留退出入口；即使地址指向任务页，也不启动业务组件、轮询或 SSE。后端同样限制为会话查询/退出和本人改密。
4. 本人改密需提供当前密码和两次一致的新密码。密码为 8—128 个 Unicode 字符且不超过 512 UTF-8 字节，不自动裁剪。成功后清会话并提示用新密码重新登录。
5. 管理员启停或重置操作员前确认具体目标。禁用/重置会撤销该账号的旧会话，重置后再次强制改密；启用不会复活旧 Cookie。初始管理员没有停用或页面重置操作，需要本机权限的恢复 CLI。

密码不进入 localStorage/sessionStorage、URL 或持久草稿，提交结束及组件卸载时清空输入；会话信息与 CSRF 仅在页面内存中。账号和 Argon2id 密码哈希在 MySQL 持久保存，网关内存会话不跨重启保留。API 的 401 清除对应旧会话；403 保留当前会话以显示权限/CSRF 错误；来自旧账号的迟到 401 不能清除后来建立的新会话。

## 状态与交互原则

- 未知组件不显示成零；固定传感器与设施不能因为出现在地图上就获得 inspect 能力。
- SSE 断连、同步、失败分别展示；旧快照不冒充新鲜数据，按后端状态判断是否允许任务操作。
- 取消表达意图，终态以任务事实为准；传输重试仍对应原 execution_key，不表示创建了新业务任务。
- 搜索分页过期要重新查询；执行动作前读取任务当前事实，不依靠旧索引内容决定状态迁移。
- 窄屏表格允许局部滚动，状态同时提供文字，表单需要错误反馈；视觉、键盘和响应式效果按实际浏览器验收，不能由构建成功代替。

## 地图与模拟控制

地图根据后端坐标呈现示意园区。人员、无人机、车辆、机器人沿加速模拟路线运动，固定传感器和设施保持位置；不做真实导航或路径优化。最近轨迹只保留本页接收的最近 30 秒、最多 20 个点，重同步和来源代次变化后重新积累，不在前端预测位置。

数量上限是演示界面范围，独立压测采用自己的输入规模。历史已有六类混合 10000 实体、100/500 events/s 的限定链路实测，不代表地图可显示 10000 点或已验证百万容量。详细语义、命令和证据见 [模拟场景说明](../simulation-map.md)；更大实体基数与独立资源运行步骤见 [规模压测手册](../operations/scale-benchmark.md)，以实际报告判断结果。
