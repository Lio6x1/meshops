# MeshOps 前端交互设计

这是基于现有后端契约的设计交付，不是生产前端，也没有连接任何服务或设备。

- [查看设计与接口边界](design.md)
- [打开离线交互原型](prototype/index.html)

直接用现代浏览器打开 `prototype/index.html`。HTML、CSS、JavaScript 均为本地文件；无需构建、依赖安装、网络或 CDN。所有交互只修改当前页面内存，刷新或“重置演示”会还原。浏览器不保存令牌、草稿、任务或偏好。

## 建议评审顺序

1. 在实体总览点击园区标记，打开六类实体详情；检查未知字段、过期快照及仅状态类型。
2. 用实体分类和名称/ID 查询筛选清单；选择人员或机器人创建 `inspect` 任务。无人机忙碌、车辆过期，当前不可选；传感器和设施不在执行实体选项中。
3. 在任务详情提交取消原因：取消意图立即显示，业务状态不会立即变为“已取消”。用详情中的“仅评审：切换状态样本”查看终态外观。这是样本切换，不模拟合法状态迁移。
4. 搜索“巡检”，翻到下一页；在底部评审面板选择“分页已过期”，然后重新查询第一页。正式搜索不返回总命中数，原型不伪造该字段。
5. 打开“可靠分发”。操作员只能查看；底部切换管理员后，填写原因并模拟人工死信重试，观察传输尝试增加、业务执行标识保持不变。
6. 打开“运行状态”：操作员看权限说明，管理员看当前 `GetStatus` 提供的三项指标及采样时间。
7. 在底部依次切换加载中、空结果、服务错误、订阅断开。断连时保留最后快照，并禁止创建依赖新鲜状态的任务。
8. 用 1440、768、390 CSS 像素宽度检查布局；窄屏表格允许局部横向滚动，主页面不应溢出。使用 Tab、Enter、Escape 检查导航、表单及原生对话框。

## 文件与接入范围

| 文件 | 用途 |
|---|---|
| `design.md` | 信息架构、状态语义、真实 RPC 映射、缺失接口与验收条件 |
| `prototype/index.html` | 页面框架、导航、评审面板、无障碍对话框容器 |
| `prototype/styles.css` | 浅色蓝/青色视觉体系与三档响应式布局 |
| `prototype/app.js` | 本地模拟数据、导航、筛选、详情、创建、取消与重试交互 |

正式接入至少需要浏览器 BFF、服务端身份与授权实体清单。现有后端没有通用浏览器 HTTP API、全量实体枚举 RPC、下发尝试集合 RPC；原型没有把这些能力当作已经存在。详见设计文档。

## 当前验证记录

- `node --check prototype/app.js` 通过；静态差异检查无空白错误。
- 使用非浏览器 Node VM 事件测试验证六页渲染、六类详情、管理员权限、过期/断连门禁、创建参数验证、输入转义、取消意图与状态分离、死信重试标识、搜索翻页与异常状态恢复。测试发现并修复了对话框标题的输入转义遗漏。
- 静态检查了 1440/768/390 的断点、窄屏表格滚动和对话框尺寸；这些检查不能替代浏览器视觉与布局验收。
- **浏览器视觉、实际键盘焦点与响应式截图尚未验收**：本次浏览器工具对本地预览的访问受限制，未通过其他服务器或浏览器绕过，也未生成或声称存在截图。用户可直接打开本地 HTML 按以上步骤评审。
